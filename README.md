# dxOverlay - Chaos Controller

Полнофункциональное приложение-оверлей для Windows, которое отображается поверх всех окон и применяет различные игровые эффекты в случайном порядке.

## 🎮 Основные возможности

### Доступные эффекты

| Эффект | Описание | Длительность |
|--------|---------|--------------|
| **Erase** | Стирает части экрана (создает прозрачные отверстия) | 30 сек |
| **Blur** | Рисует случайные линии, имитируя размытие | 20 сек |
| **Half Screen** | Закрывает левую половину экрана черным | 30 сек |
| **Disable Sensitivity** | Отключает чувствительность мыши (0.0) | 10 сек |
| **High Sensitivity** | Максимально повышает чувствительность (7.0) | 15 сек |
| **Invert WASD** | Инвертирует клавиши управления | 35 сек |
| **Invert Mouse** | Инвертирует управление мышью | 35 сек |
| **FPS Low** | Понижает максимальный FPS до 16 | 15 сек |

### Механика работы

1. **Waiting** (45 сек) - Система ждет перед началом
2. **Rolling** (5 сек) - Рулетка вращается, выбирая случайный эффект
3. **Effect** (варьируется) - Выбранный эффект активен
4. Цикл повторяется

## 🔧 Система состояний (EffectSystem)

EffectSystem реализует состояние state machine:

```
┌─────────┐
│   OFF   │ ← Система отключена
└────┬────┘
     │ StartSystem()
     ▼
┌──────────┐
│ WAITING  │ ← Ожидание 45 сек
└────┬─────┘
     │ По истечении (45 - 5 = 40 сек)
     ▼
┌─────────┐
│ ROLLING │ ← Рулетка вращается 5 сек
└────┬────┘
     │ Выбран случайный эффект
     ▼
┌──────────┐
│ EFFECT   │ ← Эффект активен N секунд
└────┬─────┘
     │ Истекло N сек
     └──────────────→ Обратно в WAITING
```

### Основные функции API

```cpp
// Инициализация
void InitEffectSystem(HWND overlayHwnd);

// Управление
void StartSystem();     // Запустить цикл эффектов
void StopSystem();      // Полностью остановить
void UpdateEffectSystem(); // Вызывать из message loop

// Получение информации
SystemState GetSystemState();
EffectType GetCurrentEffect();
bool IsEffectAlive();
DWORD GetEffectRemainingTime();

// DEV API
void Dev_ForceEffect(EffectType type);  // Принудительно активировать эффект
void Dev_ForceRoulette();               // Принудительно запустить рулетку
void Dev_StopEffect();                  // Остановить текущий эффект
```

## 💻 Как использовать

### Компиляция

```bash
# Открыть dxOverlay.slnx в Visual Studio 2022
# Выбрать конфигурацию: x64 | Debug или Release
# Build → Build Solution
```

### Запуск

Запустить `dxOverlay.exe` из папки `x64/Debug/` или `x64/Release/`.

При запуске:
1. Создается главное окно оверлея (полностью невидимое, пока нет эффектов)
2. Создается контрольная панель "Chaos Controller" с кнопками
3. Можно нажимать кнопки на панели для тестирования

### DEV Панель управления

**Контрольная панель** имеет следующие кнопки:

#### Системный контроль
- **START SYSTEM** - Запустить цикл автоматических эффектов
- **STOP SYSTEM** - Полностью остановить систему
- **FORCE ROULETTE** - Принудительно запустить рулетку сейчас
- **STOP EFFECT** - Остановить текущий эффект

#### Отдельные эффекты
- **ERASE** - Активировать эффект стирания
- **BLUR** - Активировать эффект размытия
- **HALF SCREEN** - Активировать закрытие половины экрана
- **INVERT WASD** - Активировать инверсию WASD
- **INVERT MOUSE** - Активировать инверсию мыши
- **FPS LOW** - Активировать понижение FPS
- **NO SENS** - Отключить чувствительность
- **HIGH SENS** - Максимальная чувствительность

#### Рулетка (превью)
- **PREVIEW ROULETTE** - Показать визуализацию рулетки без активации эффекта
- **STOP PREVIEW** - Остановить превью

**Важно:** Между кликами на кнопки должно пройти минимум 3 секунды (защита от спама).

## 🔄 Message Loop и обновление

Главный message loop в `Window.cpp` обрабатывает все Windows сообщения и:

1. Вызывает `UpdateEffectSystem()` - обновляет state machine
2. Обрабатывает `WM_PAINT` для отрисовки эффектов
3. Обрабатывает `WM_MOUSEMOVE` для интерактивных эффектов (Erase)

### Типичные проблемы

| Проблема | Решение |
|----------|---------|
| Эффекты не активируются | Убедитесь, что `StartSystem()` был вызван |
| Чувствительность не меняется | Проверьте, что консоль игры открывается на F7 |
| Оверлей невидим | Это нормально - он прозрачен пока эффектов нет |
| Окно не реагирует на клики | Для Erase/HalfScreen мышь захвачена - это нормально |

## 🚀 Расширение функциональности

### Добавление нового эффекта

1. Создайте `NewEffect.h/cpp`
2. Добавьте тип в `EffectType` enum в `Types.h`
3. Добавьте длительность в `GetEffectDuration()` в `EffectSystem.cpp`
4. Добавьте `#include` и инициализацию в `EffectSystem.cpp`
5. Добавьте кнопку в `ControlWindow.cpp`
6. Добавьте новую длительность в `Config.h`

### Изменение тайминга

Все тайминги в `Config.h`. Просто отредактируйте нужные константы и перекомпилируйте.
